## XMPP Component Framework

XMMP servers like ejabberd can scale to two million connections on a single node. 

They are real-time messaging powerhouses. 

This project attempts to provide a simple service framework over XMPP.

It is using C# 15/.NET 11 preview.

But I've put it on hold. I'm pivoting to an ASP.NET Core/SignalR based approach.

I may revisit this later, there's quite of lot of plubming work in place already.
